# 我的食譜庫

一個真正可以新增、整理與使用的私人電子食譜書。介面使用繁體中文（香港用語），支援手機、電腦及淺色／深色模式。電腦版可直接將食譜及圖片自動儲存到你選擇的本機資料夾；亦保留瀏覽器 IndexedDB 儲存模式。毋須帳戶、API Key 或付費服務。

## 毋須編程的電腦版

GitHub 使用者可直接 [下載 cookbook.zip](https://github.com/aesop011094/projects/raw/refs/heads/main/downloads/cookbook.zip)，解壓縮後用 **Chrome 或 Edge** 開啟 `cookbook.html`。在「設定與備份」按「選擇本機資料夾」，建立及選擇食譜資料夾，准許讀取及儲存，再按「建立並搬到資料夾」。目前食譜及上傳圖片會一併儲存，之後修改自動寫入檔案，日常使用毋須定期匯出。詳見 [下載及開啟步驟](downloads/README.md)。

圖片與程式全部包在一個 HTML 檔案內，毋須 Node.js、終端機、網絡或網站伺服器。請先把檔案保存至電腦，再以瀏覽器打開，不要只在檔案預覽視窗內預覽。舊版用戶請先關閉舊版，把新版 cookbook.html 放回原有位置並用同一個 Chrome 開啟；確認自己的食譜已顯示，再選擇新資料夾並確認搬移。

食譜保存在所選資料夾的 `cookbook.json`，每次儲存會自動保留上一份 `cookbook.previous.json`。清除瀏覽器資料不會刪除實體檔案；重新選擇同一個資料夾便可開啟。重新啟動瀏覽器後可能需要按「繼續使用此資料夾」再次准許儲存。程式不會改寫 HTML，複製 HTML 本身亦不會帶走私人食譜，換電腦時請複製整個食譜資料夾。

此雲端環境政策禁止直接開本機檔案，亦未提供操作原生系統資料夾選擇視窗的圖形桌面，因此未能在此實測雙擊啟動及系統選擇視窗；測試透過允許的本機 HTTP 網址及原生資料夾／檔案控制代碼驗證讀寫。手機或其他瀏覽器不支援資料夾儲存時，仍可使用瀏覽器儲存及 JSON 匯出。

日後程式更新，開發者可用 `npm run release` 重建 `releases/我的食譜庫.html` 及 GitHub 下載檔 `downloads/cookbook.zip`。ZIP 一定包含最新 `cookbook.html` 及附 UTF-8 BOM 的中文 `README.txt`；打包器固定檔案順序及時間並驗證 ZIP 完整性。建置需要 Node.js 及 Python 3，使用者開啟下載版不需安裝它們。

## 開啟 App

需要 Node.js 22.12 或以上（目前環境已提供 Node.js 24）。在專案目錄執行：

```bash
cd /workspace/projects
npm ci --cache /workspace/.npm-cache
npm run dev
```

開發伺服器使用 **5173** 連接埠並綁定 `0.0.0.0`，可由支援連接埠轉發的環境預覽開啟。此環境已安裝依賴並啟動開發伺服器。正式網站可將 `npm run build` 產生的 `dist/` 部署到支援 HTTPS 的靜態網站服務；尚未部署至公開網址。

## 日常使用

- **首頁及全部食譜**：即時搜尋名稱、食材與標籤，同時篩選分類、工具、時間、難度及收藏狀態。
- **食譜詳情**：調整食用人數，查看原始及換算份量，勾選食材／步驟，收藏、複製、編輯及確認刪除。食譜可透過 `#recipe/食譜ID` 直接開啟。
- **新增食譜**：上傳封面及每一步的圖片，新增食材、分開調味料，調整步驟順序，記低來源、時間、筆記與評分。JPEG／PNG／WebP 圖片會縮小以節省本機空間。
- **煮食模式**：集中顯示當前步驟、查看食材、完成步驟與倒數。人數、食材、步驟和倒數截止時間會保存，重新開啟可以接續煮食。支援的裝置會嘗試保持螢幕亮起；裝置或瀏覽器仍可能限制此功能。
- **購物清單**：從食譜加入換算後的食材，相同名稱及單位合併；可以手動增刪、修改份量、勾選與複製。數字份量與「適量」不會強行相加。
- **每週計劃**：從收藏中選擇星期一至日的早餐、午餐、晚餐；按實際日期保存，可切換週數。產生購物清單時可明確選擇取代現有內容或累加。
- **設定與備份**：選擇本機資料夾及查看自動儲存狀態，自行新增／改名／刪除分類，匯出 JSON，以及檢查及確認還原。刪除分類會將食譜移至其他分類，保留內容。

首次開啟會加入六款原創示範食譜：港式黑椒雞腿扒、薑蔥雞腿肉、魚香茄子、氣炸鍋脆皮雞腿、日式照燒雞、雞腿湯麵。食材份量、步驟與時間屬示範內容；封面是 AI 生成的示意圖片，並非實際烹調照片。詳見 [圖片與示範內容來源](public/images/SOURCES.md)。

## 文字及網頁內容匯入

目前已完成**免費、本機處理的規則式匯入**，不會將食譜傳送到第三方：

1. 按「匯入食譜」，貼上名稱、「食材」、「調味料」、「做法」等分段內容。
2. 按「整理並檢閱食譜」，在完整編輯表單確認數字、時間、分類及步驟。
3. 確認後按「儲存食譜」。匯入草稿不會自動保存。

也可貼上網頁的 Recipe JSON-LD 或包含該資料的 HTML，並保存來源網址。**貼上網址直接擷取、AI 文字整理、圖片 OCR／日文翻譯、登入及跨裝置同步尚未連接**。網站通常有 CORS／存取限制，直接擷取需要額外伺服器；AI／OCR 需要模型服務與 API Key，可能有用量費用。啟用前應另行確認服務、傳送的資料及費用。本版不會暗中呼叫任何付費服務。

## 保存你的食譜

**資料夾模式**將食譜、圖片、收藏、分類、購物清單、實際日期餐點計劃、煮食進度及外觀一併寫入 `cookbook.json`。首次選擇空資料夾需要確認搬移；選擇已有檔案的資料夾則先驗證並顯示預覽，需要確認開啟，兩邊資料不會自動合併。清除瀏覽器資料後仍可選擇同一資料夾還原讀取權限。

系統會保存上一個成功儲存版本到 `cookbook.previous.json`。若需人手還原，先關閉所有 App 視窗及另存現有主檔，確認上一份內容後複製並命名為 `cookbook.json`，再開啟資料夾。這不是無限版本紀錄，硬碟損壞或刪除檔案仍可能令資料遺失；可將此資料夾交由電腦現有的自動備份工具保存。

**瀏覽器模式**在未選資料夾或瀏覽器不支援時使用 IndexedDB，資料按網站來源（協議、主機及連接埠）分開，其他瀏覽器／裝置不會自動同步。清除網站資料、無痕模式結束或更換網站來源可能失去這個模式的資料；可選本機資料夾或匯出 JSON。

備份包括食譜、收藏、圖片、分類、購物清單、餐點計劃、煮食進度及外觀。還原前會驗證格式及關聯並顯示預覽；還原會取代現有資料，請先備份。備份檔案上限為 50 MB。

若儲存空間不足或資料夾權限失效，頁面會顯示未儲存提示並保留目前分頁的修改，可重連、騰出空間，再重試。讀取失敗時會停止寫入，保留原有資料，避免以示範資料覆蓋。兩個分頁同時編輯時，系統會檢查版本；資料夾模式亦檢查完整檔案內容，阻止舊分頁覆蓋新修改。出現衝突時可先匯出本頁資料，再確認「重新讀取最新資料」。目前沒有分頁之間的自動合併。

## 驗證

```bash
npm run build     # TypeScript 檢查及正式打包
npm test          # 份量、合併、備份及文字解析測試
npm run test:e2e  # Playwright 真實瀏覽器操作；手機與桌面
```

本雲端環境已提供 `/usr/bin/chromium`。其他機器可先執行 `npx playwright install chromium`，再執行瀏覽器測試。測試會使用獨立瀏覽器資料，不會改動你的食譜。

## 程式結構與技術選擇

採用 **React 19、TypeScript、Vite、Tailwind CSS 4、Lucide Icons、Radix Dialog 及 Zod**。Radix 提供 shadcn/ui 使用的對話框無障礙基礎，包括焦點管理和鍵盤操作。這個版本主要在本機工作，選擇 Vite 能減少不需要的伺服器配置，仍可部署為真正的 Web App。

```text
src/App.tsx                  導覽、首頁、搜尋及食譜卡片
src/types.ts                 共用食譜／計劃／購物／進度資料模型
src/store.tsx                狀態、讀取、順序儲存及重試
src/lib/storage.ts           IndexedDB adapter
src/lib/local-folder.ts      實體資料夾讀寫、版本檢查、上一份資料及權限
src/lib/backup.ts            結構、關聯、安全網址驗證及備份
src/lib/recipes.ts           份量及購物合併
src/lib/images.ts            安全讀圖及壓縮
src/data/seeds.ts            六款示範食譜及預設分類
src/components/              詳情、編輯、煮食、計劃、清單、匯入、設定
tests/e2e/                   真實瀏覽器操作測試
```

日後 Supabase 與 AI 升級方案見 [架構說明](docs/cloud-upgrade.md)。目前資料不會上傳至伺服器。
