# 我的食譜庫

一個真正可以新增、整理與使用的私人電子食譜書。介面使用繁體中文（香港用語），支援手機、電腦及淺色／深色模式。資料保存在你目前瀏覽器的 IndexedDB，重新整理不會消失，毋須帳戶或 API Key。

## 毋須編程的電腦版

GitHub 使用者可直接 [下載 cookbook.zip](https://github.com/aesop011094/projects/raw/refs/heads/main/downloads/cookbook.zip)，解壓縮後用 Chrome 開啟 `cookbook.html`。詳見 [下載及開啟步驟](downloads/README.md)。

下載 `releases/我的食譜庫.html`，用 Chrome 開啟即可使用。圖片與程式全部包在一個檔案內，毋須 Node.js、終端機、網絡或網站伺服器。請先把檔案保存至電腦，再以瀏覽器打開，不要只在檔案預覽視窗內預覽。

食譜修改仍儲存在該瀏覽器的 IndexedDB，並不會寫回 HTML 檔案。請固定使用同一瀏覽器並定期匯出 JSON 備份；複製 HTML 檔案本身不會帶走你的私人食譜。單檔內容、新增／編輯／收藏／備份及關閉瀏覽器再開的資料保存已在桌面 Chromium 透過本機測試網址驗證。此雲端環境政策禁止直接開本機檔案，未能在此實測雙擊啟動；手機的檔案預覽器及其他瀏覽器亦可能限制本機網頁執行或資料儲存。

日後程式更新，可用 `npm run release` 重新建立單檔版本（使用者開啟已產生的檔案不需執行此指令）。

## 開啟 App

需要 Node.js 22.12 或以上（目前環境已提供 Node.js 24）。在專案目錄執行：

```bash
cd /workspace/projects
npm ci --cache /workspace/.npm-cache
npm run dev
```

開發伺服器使用 **5173** 連接埠並綁定 `0.0.0.0`，可由支援連接埠轉發的環境預覽開啟。此環境已安裝依賴並啟動開發伺服器。正式網站可將 `npm run build` 產生的 `dist/` 部署到支援 HTTPS 的靜態網站服務；尚未部署至公開網址。

## 日常使用

- **首頁及全部食譜**：即時搜尋名稱、食材與標籤，同時篩選分類、工具、時間、難度及收藏狀態。
- **食譜詳情**：調整食用人數，查看原始及換算份量，勾選食材／步驟，收藏、複製、編輯及確認刪除。食譜可透過 `#recipe/食譜ID` 直接開啟。
- **新增食譜**：上傳封面及每一步的圖片，新增食材、分開調味料，調整步驟順序，記低來源、時間、筆記與評分。JPEG／PNG／WebP 圖片會縮小以節省本機空間。
- **煮食模式**：集中顯示當前步驟、查看食材、完成步驟與倒數。人數、食材、步驟和倒數截止時間會保存，重新開啟可以接續煮食。支援的裝置會嘗試保持螢幕亮起；裝置或瀏覽器仍可能限制此功能。
- **購物清單**：從食譜加入換算後的食材，相同名稱及單位合併；可以手動增刪、修改份量、勾選與複製。數字份量與「適量」不會強行相加。
- **每週計劃**：從收藏中選擇星期一至日的早餐、午餐、晚餐；按實際日期保存，可切換週數。產生購物清單時可明確選擇取代現有內容或累加。
- **設定與備份**：自行新增／改名／刪除分類，匯出 JSON，以及檢查及確認還原。刪除分類會將食譜移至其他分類，保留內容。

首次開啟會加入六款原創示範食譜：港式黑椒雞腿扒、薑蔥雞腿肉、魚香茄子、氣炸鍋脆皮雞腿、日式照燒雞、雞腿湯麵。食材份量、步驟與時間屬示範內容；封面是 AI 生成的示意圖片，並非實際烹調照片。詳見 [圖片與示範內容來源](public/images/SOURCES.md)。

## 文字及網頁內容匯入

目前已完成**免費、本機處理的規則式匯入**，不會將食譜傳送到第三方：

1. 按「匯入食譜」，貼上名稱、「食材」、「調味料」、「做法」等分段內容。
2. 按「整理並檢閱食譜」，在完整編輯表單確認數字、時間、分類及步驟。
3. 確認後按「儲存食譜」。匯入草稿不會自動保存。

也可貼上網頁的 Recipe JSON-LD 或包含該資料的 HTML，並保存來源網址。**貼上網址直接擷取、AI 文字整理、圖片 OCR／日文翻譯、登入及跨裝置同步尚未連接**。網站通常有 CORS／存取限制，直接擷取需要額外伺服器；AI／OCR 需要模型服務與 API Key，可能有用量費用。啟用前應另行確認服務、傳送的資料及費用。本版不會暗中呼叫任何付費服務。

## 保存你的食譜

資料按網站來源（協議、主機及連接埠）存放在本機瀏覽器，其他瀏覽器／裝置不會自動同步。清除網站資料、無痕模式結束、裝置故障或更換網站來源可能造成資料遺失，請定期到「設定與備份」匯出 JSON。

備份包括食譜、收藏、圖片、分類、購物清單、餐點計劃、煮食進度及外觀。還原前會驗證格式及關聯並顯示預覽；還原會取代現有資料，請先備份。備份檔案上限為 50 MB。

若儲存空間不足，頁面會顯示未儲存提示並保留目前分頁的修改，可先匯出、騰出空間，再重試。讀取失敗時會停止寫入，保留原有資料庫，避免以示範資料覆蓋你的食譜。兩個分頁同時編輯時，系統會檢查資料版本，阻止舊分頁覆蓋新修改。出現衝突時可先匯出本頁資料，再確認「重新讀取最新資料」。目前沒有分頁之間的自動合併。

## 驗證

```bash
npm run build     # TypeScript 檢查及正式打包
npm test          # 份量、合併、備份及文字解析測試
npm run test:e2e  # Playwright 真實瀏覽器操作；手機與桌面
```

本雲端環境已提供 `/usr/bin/chromium`。其他機器可先執行 `npx playwright install chromium`，再執行瀏覽器測試。測試會使用獨立瀏覽器資料，不會改動你的食譜。

## 程式結構與技術選擇

採用 **React 19、TypeScript、Vite、Tailwind CSS 4、Lucide Icons、Radix Dialog 及 Zod**。Radix 提供 shadcn/ui 使用的對話框無障礙基礎，包括焦點管理和鍵盤操作。這個版本主要在本機工作，選擇 Vite 能減少不需要的伺服器配置，仍可部署為真正的 Web App。

```text
src/App.tsx                  導覽、首頁、搜尋及食譜卡片
src/types.ts                 共用食譜／計劃／購物／進度資料模型
src/store.tsx                狀態、讀取、順序儲存及重試
src/lib/storage.ts           IndexedDB adapter
src/lib/backup.ts            結構、關聯、安全網址驗證及備份
src/lib/recipes.ts           份量及購物合併
src/lib/images.ts            安全讀圖及壓縮
src/data/seeds.ts            六款示範食譜及預設分類
src/components/              詳情、編輯、煮食、計劃、清單、匯入、設定
tests/e2e/                   真實瀏覽器操作測試
```

日後 Supabase 與 AI 升級方案見 [架構說明](docs/cloud-upgrade.md)。目前資料不會上傳至伺服器。
