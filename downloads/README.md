# 下載食譜庫電腦版

你不需要懂編程。這個版本的程式及圖片都包在一個檔案裏。

1. [下載 cookbook.zip](https://github.com/aesop011094/projects/raw/refs/heads/main/downloads/cookbook.zip)。如儲存庫是私人，請先登入自己的 GitHub 帳戶。
2. 將 ZIP「解壓縮全部」，放在電腦固定位置。
3. 在 `cookbook.html` 按滑鼠右鍵 →「開啟方式」→ **Google Chrome 或 Microsoft Edge**。
4. 在 App 打開「設定與備份」→ **「選擇本機資料夾」**。
5. 在電腦建立及選擇一個固定資料夾，例如「文件」內的「我的食譜庫」，並按瀏覽器提示准許讀取及儲存。
6. 檢查食譜數量，按 **「建立並搬到資料夾」**。目前 App 內的食譜及圖片會一併搬過去，之後修改會自動儲存，日常使用毋須定期匯出。

如果直接下載連結未能開啟，請到 [GitHub 檔案頁](https://github.com/aesop011094/projects/blob/main/downloads/cookbook.zip)，按檔案工具列的下載圖示（Download raw file）。GitHub 無法預覽 ZIP 是正常情況，請下載後再解壓縮。

## 之後點開

用同一個 Chrome 或 Edge 開 `cookbook.html`。如果瀏覽器再次問權限，在 App 按 **「繼續使用此資料夾」**，再准許儲存。等「已連接，修改後自動儲存」出現，便可正常新增及修改食譜。

私人食譜會直接存成所選資料夾內的 **`cookbook.json`**，包括上傳圖片、收藏、分類、購物清單、煮食計劃及進度。每次儲存亦會自動將上一份資料保留在 **`cookbook.previous.json`**。程式不會改寫 `cookbook.html`，也不會將食譜上傳到 GitHub 或其他服務，沒有帳戶、API Key 或額外費用。

清除瀏覽器資料不會刪除資料夾的檔案。更新版本、換瀏覽器或忘記資料夾權限後，重新按「選擇本機資料夾」，揀同一個資料夾，檢查預覽後按 **「開啟此資料夾的食譜」**。這會開啟該檔案內容，不會自動合併目前瀏覽器的食譜。

若未選擇資料夾，或瀏覽器不支援，App 仍可存於瀏覽器；這個模式下清除瀏覽器資料可能會失去食譜。舊版用戶請先關閉舊版，把新版 cookbook.html 放回原有位置並用同一個 Chrome 開啟；確認自己的食譜已顯示，再選擇新資料夾並確認搬移；不要用空白資料取代已有食譜。

換電腦時請複製 **整個食譜資料夾**，並在新電腦的 App 選擇它。硬碟損壞或人手刪除檔案仍可能令資料遺失，重要資料夾可交給電腦原有的自動備份工具處理。JSON 匯出仍可用於分享或另存副本。

## 上一份資料及測試說明

如需還原上一份，先關閉所有食譜庫視窗，另存現有 `cookbook.json`，確認 `cookbook.previous.json` 是所需資料後，複製它並將副本命名為 `cookbook.json`，再重新開啟資料夾。請勿在 App 正在儲存時移動或修改這些檔案。

食譜及封面都是示範內容；封面是 AI 生成示意圖片。雲端環境禁止直接開本機 HTML，亦未提供操作原生系統資料夾選擇視窗的圖形桌面，因此雙擊啟動與系統選擇視窗不能在此實測；瀏覽器測試透過允許的本機 HTTP 網址及原生資料夾／檔案控制代碼驗證實際讀寫。
